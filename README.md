🩺 Disease Prediction System Using Machine Learning
📌 Project Overview

The Disease Prediction System is a Machine Learning-based web application that predicts a possible disease based on symptoms entered by the user.
The system uses Python, Machine Learning, Scikit-learn, Flask, HTML, CSS, and JavaScript to provide an easy-to-use web interface for disease prediction.
The user selects or enters symptoms, and the trained Machine Learning model analyzes the symptoms and predicts the most likely disease.
Note: This project is developed for educational and demonstration purposes only. It is not a substitute for professional medical diagnosis or treatment.


🎯 Objectives
Predict possible diseases based on symptoms.
Demonstrate the practical use of Machine Learning.

🤖 Machine Learning

The system uses supervised Machine Learning to learn the relationship between symptoms and diseases.

The basic workflow is:

Dataset
   ↓
Data Preprocessing
   ↓
Feature Selection
   ↓
Train/Test Data
   ↓
Machine Learning Model
   ↓
Model Training
   ↓
Model Evaluation
   ↓
Save Trained Model
   ↓
Flask Web Application
   ↓
User Enters Symptoms
   ↓
Disease Prediction
Machine Learning Models

The project can evaluate classification algorithms such as:

Random Forest Classifier
Support Vector Machine (SVM)
Gaussian Naive Bayes

The final model used by the web application should be the model saved during the training process.



📊 Dataset

The model is trained using a disease-symptom dataset containing different diseases and their associated symptoms.

Example input:

Headache
Stomach Pain
Fever
Vomiting

The Machine Learning model processes the selected symptoms and generates a predicted disease.



🧠 How the System Works
Step 1 — User Input
The user enters or selects symptoms through the website.

Step 2 — Data Processing
The symptoms are converted into the format expected by the trained Machine Learning model.

Step 3 — Prediction
The trained classification model receives the symptom data.

Step 4 — Result
The Flask application displays the predicted disease to the user.

⚙️ Installation
1. Clone the Repository
https://github.com/adityapatil888-cmd/Disease-Prediction-System.git

Go into the project folder:

cd Disease-Prediction-System
2. Create a Virtual Environment

Windows:
python -m venv venv
Activate it:
venv\Scripts\activate

3. Install Required Libraries
pip install -r requirements.txt

If requirements.txt is not available, install the main libraries:

pip install flask pandas numpy scikit-learn
